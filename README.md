# Manoj Pal - Network Engineer Portfolio

Responsive React + Tailwind CSS portfolio based on the supplied reference design.

## Run

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Customize
- Your uploaded photo is already included as `public/profile.jpeg`.
- Replace LinkedIn/GitHub links in `src/main.jsx` with your real profiles.
- Replace phone/email if required.
- Put your real PDF resume at `public/Manoj_Pal_Network_Engineer_Resume.pdf` for the Download Resume button.
